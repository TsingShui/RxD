# Archived: Arxd moved to its own repository

This directory is no longer maintained in the RxD monorepo.

Active development, issues and releases live at:

- `https://github.com/TsingShui/Arxd` (private)

The source and history remain here for reference and for the public site links.
Do not make product changes in `apps/arxd/`; make them in the standalone Arxd
repository instead. The monorepo continues to maintain the rxd analysis CLI and
the shared Android rxd binary contract.
