# Security policy

Use GitHub's private vulnerability reporting for `TsingShui/RxD` to report a
suspected vulnerability. Do not open a public issue for an undisclosed issue.

Include the affected version or commit, a minimal input or reproduction, and the
observed impact. Never include credentials, private data, or third-party files
you are not authorized to share.

rxd treats analyzed files as untrusted input and never executes them. Reports
about parser resource exhaustion, identity mismatches, unsafe extraction, or
unexpected process execution are in scope.
