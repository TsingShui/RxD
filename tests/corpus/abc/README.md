# Dynamic Ark ABC corpus

## Offline boundary fixture

`minimal.abc` and `minimal.json` are generated by `generate.py` from the official
12.0.6.0 file/ISA definitions pinned in `crates/rxd-ark/REFERENCE.md`.

```sh
python3 tests/corpus/abc/generate.py
```

The inert fixture contains two module records, two method code items, a shared
region index, Chinese names, a surrogate pair and a MUTF8-encoded NUL constant.
`module.abc` adds a module with a default import and a local export;
`module.json` records its independent expected binding names and coordinates.
Both are handcrafted by RxD, not extracted from an application or executed.
`minimal.json` is the independent expected layout produced by the generator,
not rxd output. Ordinary tests need no network or TypeScript installation.

## Optional source oracle

`xpanda-oracle.mts` pins xpanda revision
`8f27d3ce8b63581c7eb5203bbfdfbb92e28cfccf` (Apache-2.0, author jmp0), refuses
modified tracked sources, and records metadata, original-instruction traces,
reference diagnostics, pre-simplify ASTs and reconstructed source separately.
A missing source output or reference decode failure is evidence, not success.
The full oracle is an explicit validation step, not a prerequisite for building
Rust or running offline tests. Invoke it using the reference checkout's `tsx`
with `--xpanda`, `--input` and a fresh `--output` under `target/verification/ark/`.
The default `--stage metadata` does not run decompilation. `--stage decode` adds
instruction traces; `--stage full` explicitly adds source reconstruction.
Use `--record record:0xOFFSET` to bound an individual reference source run.
