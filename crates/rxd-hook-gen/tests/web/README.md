# Web public-module offline contract

`tests/web.rs` calls `rxd_hook_gen::generate` and `publish_extension` with real options and filesystem destinations. Acorn 8.19.0 parses complete/concatenated payloads; the shared validator checks the published manifest against @types/chrome 0.3.5 and the strict MAIN/document_start/top-frame subset, pinned to minimum Chrome/Chromium 111. Dependencies are locked under `devtools/hook-gen`.

No generated hook is executed; no browser is opened or extension installed. Source inspection establishes the wrapper's raw receiver/arguments/return/throw design, not empirical Promise identity or browser hookability. Actual target availability, page intrinsics, proxies/site policies, cached references, and timing remain caller-side concerns.

Publication checks caller-editable manifests, exact local references, UTF-8 JS-only files and budgets, not JS syntax or runtime behavior. Private sibling staging and platform no-clobber directory rename prevent partial visibility and replacement of racing destinations. An existing empty directory may be removed, but nonempty directories, files and final symlinks are refused. Parent symlinks are resolved once (normal macOS `/tmp` works); callers must control the parent/ancestors against concurrent renames. Atomic visibility is not crash/power-loss durability.

Publication implementations: Linux `renameat2(RENAME_NOREPLACE)` (kernel/filesystem support required; errors do not fall back to clobbering), macOS `renameatx_np(RENAME_EXCL)`, Windows `MoveFileExW` without replace/copy flags. Host execution evidence is reported separately; implementation on another platform is not evidence that its tests ran.

Grammar: ASCII identifiers separated by dots, plus JSON double-quoted bracket keys for Unicode/reserved/escaped names. Explicit `window`, `self`, `globalThis` roots normalize to `globalThis`; implicit roots refer only to the page global, never lexical/module bindings. `constructor` and `__proto__` are forbidden even when escaped; `prototype` is explicit and allowed. The final site must be an own data property. Intermediate inherited data properties are resolved using descriptors, with a 256-level prototype traversal bound. Accessors are rejected rather than executed. Proxy traps cannot be inspected without potentially invoking page code; ordinary objects/unmodified intrinsics are explicit generated assumptions.

Chrome match subset: explicit `<all_urls>` or `http|https|file|ftp|*://HOST/PATH`, where HOST is ASCII DNS/IPv4, `*`, or `*.HOST`; `file` uses an empty host. Ports, credentials, whitespace, backslashes, IDN Unicode hosts and IPv6 are rejected (use ASCII DNS/punycode where applicable). No implicit match scope. Wait must be 1..2147483647 ms (the browser signed timer range), with monotonic deadline and at most one pending timer. Polling cannot guarantee the first late-defined call.
