CHANGELOG

What already changed.

Newest first. Public site and repository changes lead; earlier dates come from internal acceptance records and are not releases.

RoadMap ShowCase RxD

The Cargo version is 0.1.0. There is no tag or public Release yet; the anonymous installer is still pending acceptance. Only changes merged to main belong here.

2026-10-19Public preview

Public site and repository preview

  • Public site and repository preview: RxD overview, ShowCase, Arxd, RoadMap and ChangeLog.
  • English and Chinese pages with browser-language selection and a manual language switch.
  • The light Arxd mark, rounded favicon, responsive navigation and mobile menu.
  • Cargo 0.1.0; no tag or public Release, and the anonymous installer is not accepted yet.
2026-10-18Internal acceptance

Arxd Android host

  • Pi-durable workspace, independent file library, skills, MCP, context compaction and on-device GGUF models reached the product-improvement goal.
  • Pixel 10 evidence covers files, skills, activity and on-device models. Arxd remains an Android preview; no public APK.
2026-10-15Implemented

HTML lexical container

  • list and extract for lexical HTML records and byte-exact node extraction.
2026-10-14Internal acceptance

EVM static closure

  • EVMole 0.9.4 native analysis: interface, storage, CFG and metadata, plus declared on-demand pseudocode reconstruction.
  • Static navigation closure accepted; inferred results are not presented as a complete ABI.
2026-10-13Internal acceptance / design

CPython bytecode and linked Kuna

  • Static closure for the six final CPython 3.8–3.13 formats, with original instructions, explicit references and bounded whole-module source recovery.
  • Kuna CLI adapter linked directly; binwalk planned as a separate external tool with extraction semantics distinct from native carving.
2026-10-12Internal acceptance

.NET IL / C#

  • Type, member, string and semantic XREF; single-method and whole-class IL or C# reconstruction through the pinned ILSpy v11 native library.
  • Performance exceptions record the exact input, selected type and measured bound; they do not transfer to other assemblies.
2026-10-11Implemented

JS / ASAR / DEX initial closures

  • JS structures, decoded literals, lexical references and original source; ASAR entry enumeration and raw extraction.
  • DEX migrated from rasc, preserving get-class, Java output, Manifest and streaming contracts.

Unreleased / next

PyInstaller / zipapp (rxd pyz), binwalk, MCP over HTTPS, the public Release and anonymous curl installer, and an Arxd public build. Scope and status live in the RoadMap.
