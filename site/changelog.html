CHANGELOG

What already changed.

2026-11-02Public site

Site rewrite, single English tree

  • Content refreshed against the current CLI: eleven backends, the shared # row contract, Ark ABC/HAP, Lua, Flutter and EVM in the provenance grid.
  • The Chinese zh/ tree and the language switch are gone; English is the only site.
  • Pages deploy now runs: GitHub Pages is enabled with the GitHub Actions build type, so Deploy site publishes from site/.
2026-11-01Implemented

JVM throughput and freshness

  • Nested JAR/ZIP/AAR archives are parsed in parallel, and multi-release coordinates keep their archive chain.
  • Interface declarations render as valid Java, and fresh-process JAR decompilation latency is measured against the gate.
2026-10-29Implemented

ILSpy 11.2, .NET resources, musl-only Linux

  • The ILSpy native engine moves to 11.2; embedded resources and single-file bundles gain listing and byte-exact extraction.
  • Linux engines and release targets unify on musl, and the Android Bionic release path is restored.
  • Whole-PYZ Python reconstruction is parallelized, one source file per module, with measured phase timings.
2026-10-28Implemented

Ark ABC reconstruction and the unified row contract

  • Dynamic Ark ABC parsing, semantic IR and direct Oxc AST emission reconstruct the whole pinned opcode surface; ark export writes the HAP tree plus one JS file per record.
  • Every backend listing became one # header plus TAB-separated rows; references reduced to entry, context, match or context, match.
  • ZIP-family extraction runs in parallel, and PYZ navigation reads the archive index without inflating members.
2026-10-27Implemented

Lua, Flutter and EVM backends; engine-credited commands

  • rxd unluac-rs covers PUC Lua 5.1–5.5, LuaJIT 2.1 and Luau; rxd dae navigates Dart AOT snapshots; rxd evmole exposes interface, disassembly, strings and metadata.
  • Command names credit the engine, while crates, features and backend labels keep the format name.
  • Archives collapse into rxd unpack, which extracts ASAR/ZIP/HAP/PyInstaller/wxapkg byte-exactly; the HTML and JavaScript backends are removed.
2026-10-25Implemented

MCP served directly, skill printing, honest budgets

  • rxd mcp serves stdio directly with absolute-path admission; rxd skill prints the embedded skill and writes nothing.
  • Input-derived analysis and serialization quotas are gone; the remaining guards are format, recursion and expansion limits.
2026-10-19Public preview

Public site and repository preview

  • RxD overview, ShowCase, Arxd, RoadMap and ChangeLog pages.
  • The light Arxd mark, rounded favicon, responsive navigation and mobile menu.
2026-10-18Internal acceptance

Arxd Android host

  • Pi-durable workspace, independent file library, skills, MCP, context compaction and on-device GGUF models reached the product-improvement goal.
  • Pixel 10 evidence covers files, skills, activity and on-device models. Arxd now lives in the separate private repository.
2026-10-14Internal acceptance

EVM static closure

  • EVMole 0.9.4 native analysis; the surface later narrowed to the four commands whose facts the bytecode settles.
  • No control-flow graph and no recovered source ABI are exposed.
2026-10-13Internal acceptance / design

CPython bytecode and linked Kuna

  • Static closure for the six final CPython 3.8–3.13 formats, with original instructions, explicit references and bounded whole-module source recovery.
  • Kuna CLI adapter linked directly.
2026-10-12Internal acceptance

.NET IL / C#

  • Type, member, string and semantic XREF; single-method and whole-class IL or C# reconstruction through the pinned ILSpy native library.
  • Performance exceptions record the exact input, selected type and measured bound; they do not transfer to other assemblies.
