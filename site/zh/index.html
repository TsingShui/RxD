开始

构建一次，查询一切。

发布二进制从 Build RxD workflow 发布。源码构建先初始化 Kuna 路径依赖，再编译默认 all-feature profile。

git submodule update --init third_party/kuna
cargo build --release
target/release/rxd --version
target/release/rxd skill install -a pi

精简构建需显式选择：--no-default-features --features backend-js。见 安装指南。

为什么 RXD

快原语，而不是一次重调用。

内容绑定身份

每个 ID 绑定输入哈希与真实字节区间。提取返回原始字节，而不是重新构造地址。

Agent 优先输出

稳定 JSONL 信封：header、records、summary。detail 是闭合的逐记录 schema；原始源码保持字节精确。

显式预算

记录数、解码量与输入大小都有显式上限。超限是错误，输出保持原子。

诚实降级

反编译器无法恢复某个单元时，保留完整原始 IL／字节码／指令与原因，不返回部分猜测。

后端

每种格式一个命名空间。

每个后端提供适合其格式的能力闭环：枚举、搜索、交叉引用与取回。
