10 个静态分析后端

JS、ASAR、HTML、APK/DEX、JVM、.NET、WASM、PYC、EVM，以及可选的 Kuna。每个后端保留自己的查询语义、输入内坐标与原始提取能力。

已交付

Agent 入口

stdio 上的类型化 MCP、内嵌 Agent skill 与 structuredContent。Agent 不需要拼 shell 字符串；看查询示例。

已交付

跨平台单文件

macOS arm64、Linux x86_64/arm64 与 Windows x86_64。无需安装 JVM、.NET、CPython 或 Node 运行时。

已交付

性能与预算

37 项冷 CLI 工作负载；RxD 自有后端中位 6.7 ms，0/620 个采样超过 150 ms。整函数/整类例外按输入、目标与实测逐项批准。

03

明确不做

这些是边界，不是待办。能力变强也不会把它们带回来。

设计边界

人类终端 UI

只面向 Agent。不添加颜色、树形渲染、替代输出模式或为人类阅读优化的排版。

原则

先闭环，再扩展。

快原语胜过一次重调用。静态事实胜过猜测。经过实测的例外仍然是例外。

Agent 优先

低延迟、低 token 与结构化输出。不为了人类展示层牺牲查询精度。

有界

能力以内容身份、显式预算与确定性输出为边界。

实测为准

150 ms 是后端验收线。例外需要范围、release 实测与批准，不外推到其他输入。
