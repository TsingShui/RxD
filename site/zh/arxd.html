ANDROID 宿主

手机上的 RxD。

Arxd 是 Android Agent 工作区：Expo 58 + Pi-durable + 内嵌 ARM64 rxd。对话、文件、Skills、MCP 与可选端侧模型共享同一块设备。

构建说明 ↗ 设计文档 ↗

ARXD / 0.1.0 / ANDROID

工作区，不是壳。

原生页面负责交互，Pi-durable 运行 Agent 循环，RxD 执行分析。分层让一次真实查询可以在设备上走完。

端侧模型

下载固定 Qwen3.5-2B Q4_K_M（1.28 GB）或导入 GGUF。llama.rn 在 CPU 上做文本推理，最高 8k 上下文、1,024 token 回复，thinking 可选。模型不内嵌 APK；导入按 SHA-256 绑定并通过真实引擎探针。

模型连接

通过 Pi AI 接入 OpenAI Completions/Responses、Anthropic Messages 与 Google Generative AI。命名连接、模型设置与设备凭据；凭据使用 Android Keystore/SecureStore。本地 HTTP 端点有明确的未加密提示。

真实分析

内嵌 ARM64 rxd 覆盖 JS、ASAR、HTML、APK/DEX、JVM、.NET、WASM、EVM、PYC 与 Kuna。rxd_file_outline 是有界 JS 快路径，其他格式走 shell 里的 $ARXD_RXD。分析源码永不执行。

持久工作区

Pi-durable 管理对话、工具轮次与持久化。SQLite 保留历史、归档、附件与报告。删除会话不会删除文件库。

文件与 Skills

浏览、编辑、复制、分享与附加文件。导入 SKILL.md、目录或工作区技能；默认禁用，导入永不执行脚本。Agent 按需加载已准入的 Skills。

MCP 与后台进程

保存 stdio 启动定义或 HTTP(S) 端点，连接并发现工具。长任务实例可见，停止是显式动作。Android 上的明文 HTTP 仅限 loopback。

三层，各有边界。

层职责
Arxd 宿主原生页面、主题、文件选择、分享与进程管理。不是 WebView。
Pi-durable对话、工具轮次、上下文压缩、持久化与恢复。
RxD共享 Rust 后端的解析与反编译；身份、预算与输出契约不变。

端侧模型是可选路径，不改变分析身份。同一个文件从 CLI 或 Arxd 查询，得到相同的输入哈希/字节区间 ID。

能力与边界。

Arxd 是 Android 宿主，不是完整产品的保证。这些边界是设计的一部分。

仅 Android ARM64

按 apps/arxd/README.md 从源码构建。设备证据与宿主机检查分开记录；尚未发布 APK。

端侧模型不是沙箱

2B CPU 路径的能力与延迟不同于云端模型。shell 工具不提供网络隔离；不可信输入仍应在设备外隔离。

导入不等于执行

Skill 导入不运行脚本，模型文件不内嵌 APK。只启用你信任的工作流。模型导入必须通过哈希、模板与工具解析器探针。

构建与验证。

Arxd 与 RxD 同仓维护，需要 Android SDK/NDK。模型文件、APK 与设备证据不进入源码。完整前置条件与验证边界见 README。

git submodule update --init third_party/kuna
cd apps/arxd
npm ci --ignore-scripts
npm run build:rxd
python3 scripts/build-preload.py
npx expo prebuild --platform android --no-install
cd android && ./gradlew :app:assembleRelease --max-workers=2 -PreactNativeArchitectures=arm64-v8a
