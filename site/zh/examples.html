到源码。

覆盖 Android 与 .NET 的两条完整路径。命令只读；把 <id> 换成上一条输出里的真实值。

APK：找到 Authorization，再取回它的类

搜索字符串表，把命中路由到引用类，再按 descriptor 取 Java。

rxd dex strings app.apk --filter Authorization --limit 20
rxd dex xref app.apk -m Authorization --kind string
rxd dex get-class app.apk --at '<class_at>'

从 xref.context_at 取调用方方法坐标，交给 get-method --at，或取其所属类交给 get-class --at。按目标内容找引用用 -m PATTERN --kind KIND。成功以 exit 0 表示；零结果就是空 stdout。

.NET：一个方法，两种视图

成员身份由模块与 metadata token 共同确定。具备 ILSpy 引擎时可恢复 C#；--raw 保留原始证据。

rxd dotnet methods app.dll -f Add
rxd dotnet get-method app.dll --at '<at>'
rxd dotnet get-method app.dll --at '<at>' --raw
rxd dotnet strings app.dll -f hello
rxd dotnet xref app.dll --at '<method_at>'
rxd dotnet xref app.dll -m Authorization --kind string

async、迭代器、lambda 与 LINQ 语法糖由固定版本 ILSpy 恢复。无法完整重建时，保留完整原始 IL/EH 与明确原因。

把同样的查询交给 Agent

MCP 输入只接受绝对路径，默认允许所有路径；可用 --allow-path 限定文件或目录。客户端配置由你自己写入。

rxd mcp
rxd mcp --allow-path /absolute/path/to/inputs

见 MCP 指南 与 Agent 接入。

每个 ID 绑定输入哈希与字节区间；提取返回原始字节。失败时 stdout 为空。
