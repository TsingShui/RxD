ROADMAP

A roadmap
without dates.

RxD grows by closing capability loops, not by shipping calendars. Status changes only after the contract, budget and validation land on main. No date below is a promise.

01

Already shipped

Not a format checklist: each path can locate, trace and fetch a real unit.

Shipped

10 static-analysis backends

JS, ASAR, HTML, APK/DEX, JVM, .NET, WASM, PYC, EVM and optional Kuna. Each keeps its own query semantics, content-bound IDs and byte-exact extraction.

Shipped

Agent entry point

Typed MCP over stdio, an embedded Agent skill and structuredContent. An Agent does not need to compose shell strings; see the command examples.

Shipped

Cross-platform single binary

macOS arm64, Linux x86_64/arm64 and Windows x86_64. No JVM, .NET, CPython or Node runtime to install.

Shipped

Performance and budgets

37 cold CLI workloads; the RxD-owned median is 6.7 ms and 0/620 samples exceed 150 ms. Whole-function/class exceptions are approved per input, target and measurement.

Preview

Arxd Android host

An embedded ARM64 rxd, on-device GGUF and remote model connections, MCP, skills and a durable file workspace. No public APK yet; read the boundaries.

02

Next work

Contract, budget and acceptance first. Implementation follows a closed loop.

Planned

rxd pyz: PyInstaller / zipapp containers

A container entry separate from PYC. No promise of whole-tree decompilation, and container contents are not treated as verified source.

Planned

rxd binwalk: a separate external tool

Signature hits, carve results and extraction outcomes stay distinct. Native binwalk UUIDs are not wrapped as RxD content-bound IDs.

Planned

MCP over HTTPS

A transport milestone after stdio. Tool contracts, content identity and degradation semantics do not change with transport.

Pending

Public release and installer

Checksums, versioned assets and the anonymous curl installer still need acceptance. Today: source builds or Actions artifacts.

Pending

Arxd public build

No public APK yet. Build from apps/arxd/README.md; model files, APKs and device evidence stay out of source.

Ongoing

Coverage and regression

Declared EVM/WASM support ranges, corpus updates, performance exceptions and cross-platform builds are re-checked continuously. Status moves only when the loop closes.

03

Not doing

These are boundaries, not backlog items. More capability does not bring them back.

Never

Deobfuscation / string decryption

Standard literal, escape and immediate decoding is parsing. Deliberately scrambled structure and strings stay out of scope; obfuscated inputs remain useful for structure queries.

Design boundary

Human terminal UI

Agent-only. No colors, tree renderers, alternate output modes or layouts optimized for human reading.

PRINCIPLES

Close the loop first.

Fast primitives beat one heavy call. Static facts beat guesses. A measured exception is still an exception.

Agent-first

Low latency, low token cost and structured output. Query precision is never traded for a human presentation layer.

Bounded

Capability is bounded by content identity, explicit budgets and deterministic output.

Measured

150 ms is the backend acceptance line. Exceptions need scope, release measurements and approval; they do not transfer to other inputs.
