ROADMAP

RoadMap

RxD grows by closing capability loops, not by shipping calendars. Status changes only after the contract, budget and validation land on main. No date below is a promise.

01 / Done 02 / In progress 03 / Future plans
01

Done

Closed capability loops already on main.

Core

Core CLI, identity and budgets

One binary. Every result is tied to the exact input bytes. The same query returns the same records. Extracted units come out byte-for-byte.

Agent

Agent surface

Typed MCP over stdio, data-row JSONL and an embedded Agent skill.

Backends

Static-analysis backends

Each format has its own queries and IDs. Extraction follows that format's rules, not a shared abstraction.

Native JavaScript ASAR HTML Android APK/DEX JVM .NET IL WebAssembly CPython bytecode EVM bytecode
Desktop

Desktop builds

macOS arm64, Linux x86_64/arm64 and Windows x86_64.

Android

Arxd Android host

On-device Android host with models, skills and a durable workspace.

Release

Public release and installer

Public release and installer shipped.
