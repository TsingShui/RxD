EXAMPLES

From a string
to source.

Three complete paths for Android, JavaScript and .NET. Commands are read-only; replace <id> with a real value from the previous output.

APK: find Authorization, then fetch the class

Search the string table, route the hit to its referencing class, then fetch Java by descriptor.

rxd dex strings app.apk --filter Authorization --limit 20
rxd dex findrefs app.apk string Authorization
rxd dex get-class app.apk 'Lcom/example/Main;'

findrefs.detail.class is a Dalvik descriptor that can be passed directly to get-class. Exit 3 means no result, 4 means ambiguity. Only summary.complete=true means the query completed.

JavaScript: locate a request handler

No deobfuscation. Inspect structure, search decoded literals, then fetch original source by ID.

rxd js outline bundle.js --jsonl
rxd js find bundle.js --string '/api/login'
rxd js refs bundle.js --byte 122
rxd js get bundle.js --id '<id>'

get returns exact original bytes by default; add --json for a source envelope. outline gives content-bound structure IDs; find matches decoded literals; refs follows a lexical binding.

.NET: one method, two views

Member identity combines the module and metadata token. Default output recovers C#; --il keeps the original evidence.

rxd dotnet outline app.dll --method Add
rxd dotnet get-method app.dll '<id>'
rxd dotnet get-method app.dll '<id>' --il
rxd dotnet strings app.dll --contains hello
rxd dotnet refs app.dll --token 0x06000006

Async, iterators, lambdas and LINQ sugar are recovered by the pinned ILSpy engine. If reconstruction cannot produce a complete result, the full original IL/EH and an explicit reason remain.

Hand the same queries to an Agent

Register input roots and let an Agent consume typed results directly. Preview does not write configuration.

rxd mcp install -a pi --root /absolute/path/to/inputs --preview
rxd mcp install -a pi --root /absolute/path/to/inputs

See the MCP guide and Agent onboarding.

Every ID binds an input hash and byte range; extraction returns original bytes. Failures leave stdout empty.
