What the CLI answers today

Every backend but the Native engine follows one row contract: locate a unit, follow an explicit reference, then fetch only that unit. <at> is always a coordinate the previous command printed.

rxd rasc strings app.apk -f Authorization --limit 20
rxd rasc xref app.apk -m Authorization --kind string
rxd rasc get-method app.apk --at '<method_at>'
rxd jar xref library.jar --at '<method_at>'
rxd jar get-class library.jar --at '<class_at>'
rxd ilspy strings library.dll -f Authorization
rxd ilspy get-method library.dll --at '<method_at>' --raw
rxd ilspy get-class library.dll --at '<type_at>'
rxd wasm get-function module.wasm --at 'func:1'
rxd pyc modules PYZ.pyz -f networking
rxd pyc decompile PYZ.pyz -o recovered/
rxd unluac-rs xref module.luac --at 'proto:1:const:0'
rxd dae xref libapp.so --at 'str:0x7f0123'
rxd ark list method app.hap --entry ets/modules.abc
rxd ark decompile modules.abc --at '<method_at>'
rxd evmole interface runtime.hex --encoding hex
rxd kuna functions ./binary
rxd unpack app.hap -o app

Every table starts with one # column header and then TAB-separated rows; text cells are JSON-quoted and \N marks an absent value. Diagnostics and --perf go to stderr. Kuna keeps its native output.

Hand the same queries to an Agent

MCP accepts absolute paths only and permits all of them by default; --allow-path narrows to named files and directories. The client configuration is yours to write.

rxd mcp
rxd mcp --allow-path /absolute/path/to/inputs
