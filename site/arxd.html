ARXD / ANDROID HOST

Arxd

Arxd is the Android App host for RxD: it owns the App interface, Agent orchestration and Android storage/execution adapters. Hosting RxD locally does not imply that model inference is local.

Arxd is maintained in the separate private repository TsingShui/Arxd. Its App source is no longer included here; this repository is not a current Arxd build or download guide.

Current Arxd releases and capabilities are not published from this repository.

RxD itself still cross-builds for Android: the linux-bionic-arm64 target produces rxd-android-arm64.tar.gz with the default backends, MCP, the linked Kuna CLI and embedded Bionic ILSpy metadata. App packaging and device validation remain outside this repository.
