Agent RxD

One APK.
For the rest of us.

Arxd is an open-source Android Agent, built for RxD — but it works like a normal Agent too. CodeMode, Skills, MCP and a Termux environment are built in.

An Agent, a workspace, an analysis core.

A general Agent with RxD at its core. Write code, manage files, run tools and analyze targets without leaving the device.
