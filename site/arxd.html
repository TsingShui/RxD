ONE QUESTION / THE WHOLE INVESTIGATION

“Where is this APK signing the login request?”

Arxd can move from a broad question to the exact code and keep the evidence that got it there.

  1. 01 / OPENRead the target

    Manifest, classes and strings establish where to look.

  2. 02 / TRACEFollow references

    Callers, fields and types narrow the path.

  3. 03 / RECOVERGet the code

    Retrieve the relevant class or method as Java.

  4. 04 / CONTINUERun the next tool

    Inspect another file or test a finding with a script.

  5. 05 / KEEPSave the evidence

    Reports, files and tool results remain in the workspace.
