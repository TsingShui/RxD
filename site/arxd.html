WHERE IT LIVES

Host and engine are separate.

  1. Arxd owns the App

    The Android host owns the App interface, Agent orchestration and Android storage and execution adapters. It is maintained in the separate private repository TsingShui/Arxd; its App source is not included here.

  2. RxD owns the analysis

    The parsing and decompilation behind every query stay in the shared Rust backends, so an on-device host does not change coordinates, budgets or output rows.

  3. Local hosting is not local inference

    Hosting RxD on a device says nothing about where a model runs. An App can reach a hosted endpoint or run a local one; that choice belongs to the host, not to RxD.

ANDROID ARTIFACT

RxD still builds for Android.

The desktop release targets are Linux x86_64/arm64 (musl), macOS arm64 and Windows x86_64. Android is a separate Bionic cross-build, not a desktop artifact and not an App package.

rustup target add aarch64-linux-android
python3 scripts/build-ilspy.py linux-bionic-arm64
python3 scripts/build-bundled.py --target aarch64-linux-android --jobs 2 \
  --features bundled-ilspy,mcp
python3 scripts/package-release.py --target aarch64-linux-android \
  --rid linux-bionic-arm64 --name android-arm64 --no-exec

The output is target/dist/rxd-android-arm64.tar.gz with the default backends, MCP, the linked Kuna CLI and embedded Bionic ILSpy metadata. NDK 28.2.13676358 / API 24 is pinned.
