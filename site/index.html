WHY RXD

Fast is all you need.

  1. Performance

    One binary, no warm-up. Most queries finish in milliseconds, so an Agent can probe and verify repeatedly instead of waiting on one heavy call.

  2. Easy integration

    Stable JSONL and MCP over a single CLI. Add it to a shell, script or agent workflow without a daemon, database or rewrite.

  3. Beginner-friendly

    No other tools to configure. One binary and one command are enough to start exploring; no SDKs, glue scripts or setup detours.

  4. Good tech taste

    RxD chooses battle-tested decompiler engines at the frontier — Kuna, ASC, ILSpy — and pins them. Modern tooling without a stack you have to babysit.
