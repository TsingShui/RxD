WHY RXD

Fast primitives, not one heavy call.

Content-bound identity

Every ID binds the input hash and a real byte range. Extraction returns original bytes, never a reconstruction of the address.

Agent-first output

Stable JSONL envelopes: header, records and summary. Detail is a closed per-record schema. Raw source stays byte-exact.

Explicit budgets

Record, decode and input limits are explicit. Oversized work fails and output stays atomic.

Honest degradation

When a decompiler cannot recover a unit, the full original IL/bytecode/instructions and a reason remain. Partial guesses are not returned.
